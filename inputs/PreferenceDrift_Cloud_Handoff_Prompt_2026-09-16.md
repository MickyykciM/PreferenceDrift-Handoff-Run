你是我的研究合作者。请接手 PreferenceDrift 项目，先核验已有结果，再提出下一阶段可以执行的研究方案。我的导师要求使用 open-weight model。不能把调用闭源 API 的旧实验当成已经完成开放权重复现。

我目前决定：**把固定前缀、固定 assistant 确认语、只对最后回答采样的设计作为一个独立研究问题继续评估。** 它的价值是减少模型自主生成历史的扰动，提高条件可比性；不需要因为不够像自然聊天就放弃，也不预设以后必须切换成自由多轮方案 B。

目前最合适的研究问题是：

> 在题目事实与证据不变、没有模型自主生成的中间判断时，用户表达的答案偏好是否改变模型首次实际作答的分布？重复／较早的偏好表达，是否具有超出答案重复曝光和最近一次偏好提示的额外影响？

这是固定上下文中的偏好影响，不是已经观察到模型从自身正确初答漂移到错误终答。可以使用 contextual preference influence 等工作名称；不能未经操作定义就声称 belief drift 或模型改变了内部信念。

请注意：“没有模型自己生成的中间回答”不等于“没有上下文历史”。用户偏好历史和固定 `Noted.` 都是上下文。固定 `Noted.` 让条件可比，但效果的外推仍限于这种回应环境。

### 2.1 原始闭源 API 实验：已有正向信号，但存在重要解释限制

这些数据来自最初交接包，不是本轮新跑的开放权重实验。

早期 pilot：20 题、2 条件、4 轮、160 条模型回答；被测 `gpt-4o-mini`，`gpt-4o` 裁判。末轮错误率 baseline 20%，progressive 65%，差 +45 个百分点。缺少 final-belief-only 条件，无法拆分较早历史与最后误导消息的贡献。

后续全量：100 题、3 条件、300 对话、1,200 回答，模型阶段零失败；被测仍是 `gpt-4o-mini`。末轮误导消息在 belief-only 与 progressive 间相同。

| 裁判／原错误口径 | baseline | belief-only | progressive | progressive − belief-only |
|---|---:|---:|---:|---:|
| gpt-4o | 19/100 | 52/100 | 87/100 | +35 pp |
| gpt-4.1-mini | 15/100 | 22/100 | 52/100 | +30 pp |

原错误口径包含 incorrect 和 unclear；不是把所有 partial 都算错。严格只计 incorrect 时，gpt-4o 的 belief-only 为 49/100，mini 为 21/100；不要混用口径。

离线复核可重算出 progressive vs belief-only 的精确 McNemar p，分别约 5.82e-11、2.27e-7，但统计差异不自动证明“纯偏好累积机制”。主要限制：

- 初答没有冻结共享：belief-only 对 baseline 的初答文本有 86/100 不同；progressive 对 belief-only 有 85/100 不同。不能按同一个初始回答的反事实分支来叙述。
- 不同历史中包含替错误观点作同情性解释等任务变化，不只是单纯声明偏好；没有干净的重复曝光控制。
- 双裁判严格度明显不同；40 条所谓人工仲裁来自裁判分歧子集且有 AI 辅助，不能当随机独立人工验证。

- 原报告中“已经证明纯累积效应”“机制成立”等表述过强，不能直接沿用。
